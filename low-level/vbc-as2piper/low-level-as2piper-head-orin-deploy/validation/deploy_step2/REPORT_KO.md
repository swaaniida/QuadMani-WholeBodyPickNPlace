# 2단계 사전 검사: 위치·그리퍼 방향 연동 Workspace

**상태: 검사 완료, 학습 샘플러 적용 전 사용자 검토 대기.** 기존 코드·reward·PPO·DR·gain·관측·action 설정 미변경. Full Training 및 optimizer update 없음.

## 자산과 검사 방법

- 복제본 `low-level-as2piper-head-orin-deploy`의 카메라·거치대 포함 URDF 사용.
- URDF SHA256: `8df7eb7b18d68bb376eca680bd09f256f8bd6f8cdfd9083d2fe5028fc0733139`.
- 총 명목 질량: **23.43034047413kg**. 이번 검사는 DR 없는 명목 모델. 질량·관성 실측 확인은 6단계 대상.
- 기존 분석 도구의 기구학 함수를 `geometry_tools.py`로 복사하고 자산·출력 경로를 이번 복제본/검사 디렉터리로 분리. 이전 보고서 및 MJCF 덮어쓰기 없음.
- 평지, 발 중심 높이 0.028m, 네 발 XY 위치 고정 Leg IK + Arm 위치·방향 6D IK.
- 몸통 후보: (높이m, pitch°) = (0.3244,0), (0.3244,-15), (0.30,15), (0.30,25), (0.27,30), (0.27,35).
- 목표: 전방 기준 x=0.45/0.60/0.75/0.90/0.975m × 지면 기준 z=0.02/0.10/0.30/0.50/0.70/0.85m × 가상 중심 주위 yaw=-0.30/0/+0.30rad = 90개.
- yaw≠0에서 전방 x는 `center_x+(x_nominal-center_x)*cos(yaw)`. 표의 전방 최대치는 yaw=0과 일치하는 nominal x임.
- 위치 오차 <3mm, 방향 오차 <2°. 종점에서 다리·팔 관절한계 여유 ≥5° 및 정적 지지 다각형 CoM 여유 ≥20mm. 설계 검사 여유이며 제조사 안전 인증값 아님.
- URDF collision을 MuJoCo 충돌 형상으로 검사. 같은 fixed 조립체와 직접 연결된 인접 링크는 제외하고 다른 링크/지면의 1mm 초과 관통 거부. 메시 충돌은 MuJoCo convex 근사이므로 CAD 정밀 충돌 판정이 아님.
- 비음수 발별 수직 지지력을 풀어 free-base 중력 wrench 균형 확인. 그 지지력으로 다리 중력 지지 토크와 팔 중력 토크 산출, URDF effort와 비교.
- 홈→종점에 대해 9개 joint-space 중간 자세 및 **13개 실제 구면 보간 중간 목표**를 검사. 구면 경로의 각 지점에서 Leg+Arm IK·충돌·CoM·정적 지지/URDF effort 검사. 경로는 URDF hard limit 내이며 5° 여유는 종점 기준. 중간 자세 간 연속 충돌이나 속도·가속도·관성 토크 검증은 아님.

## 방향식 비교

동일한 확장 위치 90개에서 **방향식만** 비교했다. 현재 학습 범위 자체를 바꿔 실행한 결과나 학습된 정책의 성능이 아님.

- 기존 방향식: `tool_pitch = 2.455216137744035 - sphere_elevation`.
- 후보: 상단/홈에서는 기존 식을 유지. 목표 z가 0.25→0.10m로 내려가면서 아래 방향식으로 선형 혼합.
- 바닥 방향 후보: 전방 x가 0.55→0.975m일 때 `tool_pitch = 175→150°`, 이후 양 끝 고정.
- yaw는 구면 방위각과 연동, tool roll=0. 추가 무작위 orientation perturbation은 이번 검사에 넣지 않음.
- 이 TCP 축에서 pitch=180°가 수직 아래 방향. 150°는 수직 아래에서 전방으로 30° 기울어진 방향.

## 바닥 자세·토크 예시 (yaw=0, TCP z=0.02m)

| 전방 목표 | 찾은 몸통 높이 / 숙임 | tool pitch | 팔 joint2 중력 토크 절댓값 |
|---|---|---:|---:|
| 0.60m | 0.30m / 15° | 172.1° | 8.10Nm |
| 0.75m | 0.30m / 15° | 163.2° | 10.20Nm |
| 0.90m | 0.30m / 25° | 154.4° | 11.92Nm |
| 0.975m | 0.27m / 30° | 150.0° | 12.83Nm |

검사를 통과한 홈→종점 경로에서 팔 joint2의 중력 필요 토크 최대는 약 **13.11Nm**다.

**토크 해석:** URDF의 PiPER 전 관절 effort=100Nm는 실기 연속/피크 정격 확인값이 아니다. 이번 torque pass는 URDF 값과의 비교이며, 전방 0.975m를 실기 운용 가능하다고 판정하는 근거가 아니다. 공식 토크·열 제한, 실제 질량, payload, 동적 가속도를 확인한 뒤 채택 여부를 결정해야 한다.

전방 0.975m 예시의 정적 네 발 하중 해는 앞발 약 92.5/92.8N, 뒷발 약 22.2/22.4N이다. 네 발 지지가 가능한 자세가 존재하지만, 학습된 정책이 이 자세를 실현한다는 증명은 아니다.

## 적용 권고안 — 아직 미적용

1. **위치·방향·전신 자세 후보를 오프라인에서 검사한 후보 집합**을 만든다. 학습 중 반복 IK 탐색을 추가하지 않는다.
2. 반경·고도각·yaw를 독립적으로 균일 추출하지 않고, 검사한 위치와 연동된 방향을 함께 추출한다. 통과 표본의 외접 범위 r=0.2745~0.8682m / 고도각=-1.0935~1.0503rad / yaw±0.30rad 전체가 유효한 것은 아니다.
3. **현재 목표→다음 목표의 구면 보간 경로를 사전 검사**하고 허용된 전이만 선택한다. 이번에 검사한 것은 홈→각 목표이며, 통과한 69개 목표 사이의 임의 조합을 허용한다는 뜻이 아니다. 필요하면 홈 경유를 검토한다.
4. 상단/초기 FK 방향 정합성은 유지하고, 지면 부근에서 방향을 위치에 연동한다. Leg IK 해는 가능 자세의 증거로 저장하며 학습 중 다리 자세를 직접 강제하지 않는다. 정책의 실제 전신 동작은 후속 rollout에서 확인한다.
5. 실기 토크 제약 미확정 후보에는 필요 토크와 **hardware torque 미확인** 상태를 저장한다. 임의 Nm 한계를 확정하거나 100Nm를 실기 정격으로 간주하지 않는다.
