# 사용자 확인 버전: 기본 PiPER / S-V1.5-8 / piper_sdk 0.6.1

- 공식 PyPI 0.6.1 wheel을 SHA256 검증 후 소스 열람용으로만 저장했다. 설치·실기 실행 없음. GitHub 태그 0.6.1 commit은 `081e7c588e5b79eeaefa67a0469bcc701c81014f`.
- 0.6.1 `__JointMitCtrl`은 t_ref를 [-8,8] 범위의 8-bit 값으로 직접 인코딩한다. 최신 pyAgxArm의 SI 토크 환산 API와 동일한 인터페이스가 아니다. 이 ±8을 URDF effort나 모터 연속 정격으로 복사하지 않는다.
- 버전별 기계 정격이 바뀐다고 해석하지 않는다. 펌웨어/SDK별 명령 스케일·제한과 모터의 기계적 연속/피크/열 한계를 구분한다.
- 공식 최신 정정 문서에 따르면 S-V1.5-8부터 속도 raw 단위는 0.01rad/s다. 3rad/s 명령은 raw 300에 해당. 0.6.1에 남은 0.001rad/s 주석을 그대로 쓰면 10배 오류 위험이 있다.
- 가속도는 0.6.1에서도 조회 0.001rad/s², 설정 0.01rad/s² 표기가 혼재한다. 명령별 단위가 다른 것인지 표기 오류인지 확정하지 않았으며 임의 통일하지 않는다.
- 0.6.1 message table의 joint6 ±120°와 최신 preset의 ±170°도 차이가 있다. 실제 제한 조회 전 기존 URDF 한계각을 임의 변경하지 않았다.
- VBC 실기 팔은 독립 800Hz IK 기반 제어기로 기술된다. 공개 학습 코드에서 50Hz IK 계산을 한다는 사실과 구분한다. 공개된 실기 구현 없이 50Hz 해를 800Hz로 단순 보간한다고 단정하지 않는다.
- 이번 질문 응답에서는 학습 코드/gain/effort/학습 주기를 추가 변경하지 않았다.
