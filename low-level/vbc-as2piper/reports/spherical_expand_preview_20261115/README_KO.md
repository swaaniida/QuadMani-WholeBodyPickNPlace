# 구면 범위 확대 미리보기

- 현재: 가상중심[0.28,0,0.50]m, r0.35~0.65m, 고도각−47.60~50.28°, 좌우각±0.30rad.
- 후보: 같은 중심, r0.35~0.80m, 고도각−36.87~38.68°, 좌우각±1.20rad. 좌우각은 원본 VBC b1z1_config.py의 값과 동일.
- 높이0.02~1.00m를 지키도록 후보 고도각을 다시 계산. 기존 고도각을 유지하고 반경만0.80m로 늘리면 높이−0.09077~1.11538m가 되어 높이 제한을 벗어남. 고도각을 유지하는 대안은 높이 초과 목표를 별도로 제외하는 구면 절단 방식이며, 이 그림은 독립 구면 추출을 유지하는 고도각 조정안임.
- yaw0: 바닥z0.02의 전방x0.920m, 상단z1.00의 전방x0.90450m, 중간z0.50에서 최대전방x1.080m. 모두 몸통XY/yaw에 따른 가상좌표계 기준. yaw≠0에서는 전방성분이cos(yaw)만큼 줄어듦.
- workspace_preview.png: 최신 카메라 포함 URDF MuJoCo 렌더. 파랑 현재, 주황 후보. 점은 경계 위치이며 IK 성공 표시가 아님.
- 이번 작업은 형상 미리보기이며 후보에 대해 IK·충돌·토크 검사하지 않음. 도달 가능 범위로 인증하지 않음. 학습 코드·config·URDF·reward·기존 checkpoint 변경 없음. render.py에서 config hash 전후 일치 확인. 학습/GPU 실행 없음.
