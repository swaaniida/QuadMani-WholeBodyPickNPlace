# AS2 gait 원인 가설 및 비교 범위

| 원인 후보 | 확인한 사실 | 비교 방법 |
|---|---|---|
| 발 속도 캐시 고정 | 초기 tensor-index 복사본이 갱신되지 않음. 실제 속도가 변해도 캐시 변화0 | velocity 단독 |
| 충격 변화 패널티 비활성 | 상태를 저장/확인하는 객체가 다름. 기존 항목은0 | jerk 단독 |
| 정지 contact 목표 불일치 | 정지 desired contact가 네 발 모두0.5. 부호 보정된 force penalty와 충돌 | stop 단독, data_stop 조합 |
| 초과 속도 보상 포화 | 목표0.25와 실제0.55m/s 모두 거의 최대 보상 | data_stop 대비 speed |
| yaw 추종 유인 부족 | 기존 weight0.5, Gaussian denominator0.2 | speed에서 yaw weight1.0, sigma0.35rad/s와 함께 비교 |
| 발 높이 기준 | 앞발2개 world-z norm이며 개별 발 위상·반지름·지면을 반영하지 않음 | speed 대비 stable 조합 |
| 체공시간과 gait 주기 불일치 | 앞발만0.5초 기준.2Hz/duty0.5의 swing 시간은0.25초 | stable 조합: 네 발,0.25초, credit 상한 |
| 초기 자세 근접 보상 | walking_dof는 발 디딤이 아니라 home 관절 근접도를 보상 | stable 조합: weight1.5→0.5 |
| 초기 학습 부족 | 기존313회 정책은3.25Hz였으나 원래 보상으로 평지120회 추가 학습 후2Hz | 공통 초기 정책 및 동일 추가 학습량의 대조군 |
| 거친 지면·강한 DR | 초기 학습을 어렵게 할 수 있으나, 평지·DR off 대조군에서도 과속/정지 실패가 남음 | 비교군은 공통 controlled 환경. 선정안은 별도 rough/DR 평가 |
| torque clipping | 기존 전진 평가의 limit90% 초과 샘플0%, 최대사용비율71.3% | 주원인으로 지지되지 않음. 모든 조건에서 하드웨어 동일 |
| PD/armature 및 CoM | 모델에 영향을 주지만 이번 비교에서는 변경하지 않음 | 보상 효과와 섞지 않음. 최적 게인·구조라는 주장 없음 |
| 팔 동작 | 모든 비교 조건에서 동일한 full random EE command 사용 | 선정안의 EE 오차도 확인. 팔 목표 범위를 줄여 결과를 숨기지 않음 |
| 발 인덱스/영상 변환 | FL,FR,RL,RR 순서 및 trot pair 확인. PhysX↔MuJoCo 발 z 오차2.38e-7m | 영상 원인으로 배제 |

`data_stop`은 세 코드 수정의 조합이다. `speed`와 `stable` 역시 명시된
여러 변경을 묶은 조건이므로, 조합 내부의 개별 weight 효과를 분리했다고
주장하지 않는다. 단일 seed120회 회복 실험의 결과는 장시간 scratch 수렴이나
실물 안정성의 증명이 아니다.

실제 수치는 `experiments/gait_ablation_v1/PAIRED_COMPARISON_KO.md`에 기록한다.

## 거친 지면의 높이 기준 추가 진단

하중 20N 초과의 발 접촉 3,767개 샘플에서, 발 바닥 높이와 3이웃 grid
추정치의 절대 차이는 중앙값 0.76cm, P95 4.35cm, 최대 10.11cm였다.
샘플의 13.49%는 2.5cm보다 컸다. 기존 clearance sigma 2.5cm와 비교할 때
보상 오차에 영향을 주는 크기다. 접촉 높이도 구형 발 반지름과 경사면 때문에
근사이므로 이 수치를 정확한 CAD 표면 오차로 해석하지 않는다.

v2는 접촉 높이 캐시와 거친 지면의 최소 clearance 조건을 조합해 비교한다.
기존 평지 검증의 보상 식, 관측, EE 범위, 하드웨어는 바꾸지 않는다.

## VBC 환경의 초기 정지 편향

full rough/DR에서 Gaussian 수정안은101/201회 시점에 이동 명령에도 몸통 속도가
거의0이었다. 2Hz 접촉 성분이나 긴 episode만으로 보행 성공을 판단할 수 없다.
같은101회 정책의 privileged/history 경로를 처음10초로 맞춰 비교해도 둘 다
거의 움직이지 않았으므로 이 시점의 실패를 history 적응만으로 설명하기 어렵다.
목표 속도가0.6m/s일 때 sigma0.2m/s Gaussian의 정지 보상은 exp(-9)로 작다.
작은 이동에서 보상 차이를 더 명확히 주는 `progress` 조합을 같은 환경에서 비교한다.
이는 초기 학습 가설이며600회 이후 Gaussian의 성능도 별도로 추적한다.

초기 두 진단 평가에서 최종 `/100`을 빠뜨린 검증식 때문에 저장이 중단됐고,
원시 물리 로그에서 복구한 결과는 partial artifact로 구분했다. 이 오류는 학습에
영향을 주지 않았다. 수정 후 본 평가의 보상 합산 오차는6e-8 이하다.
